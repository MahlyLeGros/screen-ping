# Scripts

Helpers you don’t need every day. Daily starters stay at the **repo root**
(`start-local.bat`, `start-online.bat`, `start-all.bat`, …).

| Script | Purpose |
|--------|---------|
| `build-all.bat` | Rebuild web + desktop |
| `launch-online-core.bat` | Used by `start-online.bat` / `start-all.bat` |
| `show-ngrok-url.ps1` | Print / copy ngrok HTTPS URL |
| `build-installer.bat` | Build the Windows Setup.exe |
| `package-for-friend.bat` | Installer + docs → `out/screen-ping-share.zip` |
| `test-logo.bat` | Pack desktop + start local server to check icons |
